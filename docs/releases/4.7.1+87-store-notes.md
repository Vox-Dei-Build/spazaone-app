# Spaza One 4.7.1+87 store notes

Release target: Google Play Internal and Apple TestFlight.

## Google Play — What's new

Spaza One now uses less data to download and less space on your phone. This
update keeps the Billing, catalogue, order and Android 16 improvements from
4.7.0, with no changes to how you use the app.

## App Store — What's New

This update reduces the app's download size and keeps the latest Billing,
catalogue and order improvements. There are no workflow changes in this
maintenance release.

## GitHub release summary

Spaza One 4.7.1 is a size-focused maintenance release. It removes unused
runtime packages, optimises bundled images, and restores Android R8/resource
shrinking with verified Flutter/plugin keep rules. The minified API 36 release
starts successfully with Crashlytics and Firebase Messaging registered.
