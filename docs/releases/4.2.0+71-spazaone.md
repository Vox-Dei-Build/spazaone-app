# SpazaOne 4.2.0+71 release preparation

This document prepares the existing Pasella app record for its customer-facing
rename to SpazaOne. It does not authorize an upload, TestFlight build, Google
Play release, store metadata save, tag or deployment.

The authoritative release path remains the tag-driven CodeMagic workflows in
`codemagic.yaml`. After approval, tag `main` with `v4.2.0+71`; CodeMagic builds
and publishes Android to Play Internal and iOS to TestFlight. Local builds are
diagnostic only and are never the upload source.
